# Chauffeur releases

Downloads of [Chauffeur](https://chauffeur.askdialog.com), by Dialog: the macOS disk image, its SHA-256 checksum and the Linux bundle Chauffeur's cloud workers install, published under [Releases](https://github.com/askdialog/chauffeur-releases/releases).

This repository holds release files only, no source code. Chauffeur updates itself from the releases published here.
